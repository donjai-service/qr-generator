QR Generator Standalone for Windows

วิธีใช้
1. แตกไฟล์ zip
2. เปิดโฟลเดอร์ qr-generator-standalone
3. ดับเบิลคลิกไฟล์ "QR Generator.html"
4. ใช้ใน Chrome, Edge หรือ Firefox ได้เลย

ไม่ต้องติดตั้ง Python
ไม่ต้องติดตั้งโปรแกรมเพิ่ม
ไม่ต้องใช้ AI token
ไม่ต้องเปิด server

ฟังก์ชัน
- ใส่ URL หรือข้อความ
- ปรับสี QR
- ปรับสีพื้นหลัง
- เลือกขนาด PNG
- ติ๊กเลือกใส่โลโก้หรือไม่ใส่
- เลือกไฟล์โลโก้ PNG/JPG/WebP
- ดาวน์โหลด PNG

หมายเหตุ
- เป็น QR แบบธรรมดา จึงไม่ track จำนวนสแกน
- ถ้าใส่โลโก้ใหญ่เกินไปอาจทำให้สแกนยาก ควรใช้โลโก้เรียบ ๆ และทดสอบสแกนก่อนใช้งานจริง
