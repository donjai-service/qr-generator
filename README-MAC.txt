QR Generator Standalone for Mac

วิธีใช้
1. เปิดโฟลเดอร์ qr-generator-standalone
2. ดับเบิลคลิกไฟล์ "QR Generator.html"
3. ถ้าเครื่องถาม ให้เลือกเปิดด้วย Safari, Chrome หรือ Edge

ไม่ต้องติดตั้ง Python
ไม่ต้องติดตั้งโปรแกรมเพิ่ม
ไม่ต้องใช้ AI token
ไม่ต้องเปิด server

ฟังก์ชัน
- ใส่ URL หรือข้อความ
- ปรับสี QR
- ปรับสีพื้นหลัง
- เลือกขนาด PNG
- ติ๊กเลือกใส่โลโก้หรือไม่ใส่
- เลือกไฟล์โลโก้ PNG/JPG/WebP
- ดาวน์โหลด PNG

หมายเหตุ
- ไฟล์ที่ดาวน์โหลดจะอยู่ในโฟลเดอร์ Downloads ตามค่าเริ่มต้นของ Browser
- เป็น QR แบบธรรมดา จึงไม่ track จำนวนสแกน
