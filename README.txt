QR Generator Standalone

เปิดได้ทั้ง Windows และ Mac โดยไม่ต้องติดตั้ง Python หรือโปรแกรมเพิ่ม

วิธีใช้
1. เปิดโฟลเดอร์ qr-generator-standalone
2. ดับเบิลคลิกไฟล์ "QR Generator.html"
3. ใส่ URL หรือข้อความ
4. เลือกสี QR / สีพื้นหลัง / ขนาด
5. ถ้าต้องการโลโก้ ให้ติ๊ก "ใส่โลโก้ตรงกลาง QR" แล้วเลือกไฟล์โลโก้
6. กด "ดาวน์โหลด PNG"

ไฟล์ PNG จะถูกบันทึกไว้ใน Downloads ของ Browser
